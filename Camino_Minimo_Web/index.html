Cómo se usa

      
    
        
  1. Elige la cantidad de vértices (de 5 a 15) y si el grafo es dirigido. Cambiar cualquiera de los dos genera una matriz nueva.
    2. 
        
  2. Pulsa «Generar aleatoria» o escribe los pesos en la matriz.
          
      
            
    • Celda vacía o «-»: no hay arista.
      • 
            
    • 0 es una arista que existe y no cuesta nada.
      • 
            
    • La diagonal siempre es 0.
      • 
            
    • Si el grafo no es dirigido, la matriz se mantiene simétrica sola: al escribir [i, j] se copia en [j, i].
      • 
          
    
        
    3. 
        
  3. Elige el origen y el destino y pulsa «Calcular ruta».
    4. 
        
  4. Usa «Anterior», «Siguiente» o «Reproducir» para recorrer las iteraciones. En computadora también sirven las flechas ← y → del teclado.
    5. 
        
  5. Arrastra los vértices para acomodar el dibujo, o pulsa «Reordenar vértices» para sortearlos de nuevo. Al pasar el mouse sobre un vértice se resaltan sus aristas.
    6. 
      

      
Las filas y columnas siguen el orden de los vértices: 0, 1, 2, …
